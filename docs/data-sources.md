# データソース

正本。パースや指標の定義はここを先に直す。

## 調査

- 日本政府観光局（JNTO）「訪日外客統計」
- 公表ページ: https://www.jnto.go.jp/statistics/data/visitors-statistics/
- 利用条件: 出典「日本政府観光局（JNTO）」の明記で引用可、連絡不要（同ページ）
- 同じ数字を載せる [statistics.jnto.go.jp](https://statistics.jnto.go.jp/) はダウンロードに利用申請が要るので使わない

## 取り込む表

ファイル名は公表日つきで毎月変わる。`npm run fetch` がページのリンク文字列から探す（`src/lib/data/sources.ts`）。

| キー | ページ上の表 | 形式 | 範囲 |
| --- | --- | --- | --- |
| `monthly` | 国籍/月別 訪日外客数 | xlsx（1年1シート） | 2003年1月–最新月 |
| `purpose` | 国籍/目的別 訪日外客数 | PDF のみ（1年1ページ） | 2004–2025 |
| `annual` | 年別 訪日外客数、出国日本人数の推移 | PDF のみ | 1964–2025 |

PDF は poppler の `pdftotext -layout` で読む。正規化 JSON（`data/normalized`）と配信データ（`public/data`）は追跡し、`data/raw` は追跡しない。

## 列・行（一次確認済み: 2026年9月16日公表分）

### 月別（xlsx）

- 「1月」〜「12月」と「累計」の見出し行から列を決める。2008・2009年は「累計」でなく「年計」。
- 名前は 2020年以降が2列（2列目は中東地域・北欧地域の内訳）、それ以前は1列。
- 州は「アジア計」のように「計」つき。「無国籍・その他」はオセアニア計の直後に「計」なしで並ぶが、州と同列に扱う。
- 2015年以前は「その他アジア」など「その他◯◯」の行がない。2022年は北欧4か国を並べるだけで「北欧地域」の行がない。
- シート末尾の注２が、その年が確定値か、斜体が推計値かを宣言する。斜体は xlsx 内の styles.xml とシート XML から読む（SheetJS 無償版はフォントを返さない）。確定年の斜体（2008年の2セル）は推計として扱わない。
- 推計値は百人単位に丸めてある。年の途中では、州の行は推計の月に値がない。

### 目的別（PDF）

- 目的は 観光客・商用客・その他客。2004–2006年は「一時上陸客」の列が加わる。
- 行頭の字下げが階層: なし＝州、2字＝国・地域、4字＝内訳。
- 人数と伸率が交互に並ぶが、2007年は観光客の伸率が抜ける。伸率は小数点か記号を含むので、小数点のない整数だけを人数とする。
- 定義（PDF 注1）: 「観光客」は短期滞在入国者から商用客を引いたもので、親族・友人訪問を含む。「その他客」は観光・商用以外で、留学・研修・外交・公用などを含む。

### 年別（PDF）

- 1行1年。人数は桁区切りつきの2つ（訪日外客数・出国日本人数）。
- 注: 1964–2025年はすべて確定値。出国日本人数は法務省出入国管理統計による。

## 定義（画面の注記に出す）

訪日外客は、法務省集計の外国人正規入国者から日本を主たる居住国とする永住者等を除き、寄港地上陸・通過上陸・船舶観光上陸の外国人を加えた数。駐在員・その家族・留学生などの入国者・再入国者を含み、乗員を含まない（JNTO 報道発表の注）。観光客そのものではない。

## 検証（`npm run verify`）

3表を突き合わせる。

- 年別の訪日外客数 ＝ 月別の総数の累計 ＝ 目的別の総数（2004–2025）
- 国・地域ごとの月別の累計 ＝ 目的別の総数
- 州の合計 ＝ 総数。内訳の合計 ＝ 親（「その他◯◯」がない年の州は親以下）
- 確定年は12か月の合計 ＝ 累計。目的の合計 ＝ 行の総数
- 推計を含む月は、子1つにつき百人のずれを許す
